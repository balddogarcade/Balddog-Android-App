# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.3.x` (latest release) | :white_check_mark: |
| `< 0.3.0` | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in **bald.dog ARCADE** (Android app, Rust core, netplay transport, or backend configuration), please report it responsibly:

1. **Do not** open a public GitHub issue with exploit details.
2. Contact the maintainer privately via GitHub Security Advisories (`Security → Advisories → Report a vulnerability`) or at `security@bald.dog`.
3. Include steps to reproduce, affected versions, and potential impact.

We will acknowledge receipt within 72 hours and work on a fix and coordinated disclosure.
