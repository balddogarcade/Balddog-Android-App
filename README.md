# bald.dog ARCADE (Android)

Native **bald.dog ARCADE** client for Android (`arm64-v8a`). It combines a modern **Kotlin + Jetpack Compose** interface with an emulation and rollback netplay engine written in **Rust** (`wgpu`, `oboe`, `ggrs`) on top of **FinalBurn Neo (libretro)**, backed by **Supabase** and **IPFS** for the game catalog, multiplayer rooms, and verified ROM/BIOS downloads.

---

## Key Features

- **Native Rust Engine (`balddog-core`)**:
  - Dynamic loading of the `libfbneo_libretro.so` core via `libloading`.
  - Video rendering with `wgpu` attached to the native Android surface (`Surface` / `ANativeWindow` via JNI).
  - Low-latency audio using `oboe` and a ring buffer (`ringbuf`).
- **LAN & Online Multiplayer (`balddog-netplay`)**:
  - P2P rollback netplay powered by **GGRS**.
  - Local network match discovery via Android NSD (`LanNsdManager`).
  - Real-time lobbies, player slots, and chat with **Supabase Realtime**.
- **ROM & BIOS Management (`IpfsRomManager`)**:
  - Downloads from IPFS with integrity verification (`sha256` / `crc32`) based on the catalog and BIOS (`game_bios`) defined in Supabase.
- **Competitive Leaderboards & 1CC Engine (`rcheevos`)**:
  - Real-time memory scanning of `RETRO_MEMORY_SYSTEM_RAM` via the embedded `rcheevos` evaluation engine.
  - Strict **1CC (One Coin Clear)** enforcement: scores are only submitted if completed with 1 credit.
  - In-game live score indicator & 1CC eligibility in `InGameQuickMenu`.
  - Global Top 50 leaderboards and personal rank sheets with offline score queuing (`PendingScoreQueue`).
- **Deterministic Replays & Anti-Cheat (`.bsv.gz` / MP4)**:
  - Automatic frame-by-frame `BSV1` input recording (gzip-compressed) during ranked 1CC sessions, stored in Supabase Storage.
  - Headless server-side replay verifier (`verify_replay.rs` and Python worker) preventing hacked score submissions.
  - Watch any Top 50 replay from `GameLeaderboardSheet` with `1x / 2x / 4x` speed controls, play/pause, restart, and progress HUD (`ReplayHudOverlay`).
  - Export PNG screenshots (`Pictures/balddog ARCADE/`) and H.264 MP4 video clips (`Movies/balddog ARCADE/`) locally via Android `MediaCodec` + `MediaMuxer` + `MediaStore`.
- **P2P Netplay & Voice Chat**:
  - Rollback netplay via GGRS with LAN discovery (`LanNsdManager`) and STUN NAT traversal.
  - Low-latency P2P voice chat with Opus compression, jitter buffering, and Voice Activity Detection (VAD).
- **Gamification, Social & Rankings**:
  - Global rankings, rebalanced `ArcadeRank` tiers (Novato to Leyenda), medals, and follower network.
  - Public profile screens with activity history and game statistics.
- **Adaptive Controls**:
  - Physical gamepad support (`ControllerManager`, `RetroJoypad`).
  - Customizable touch overlay (`ArcadeTouchOverlay`, `TouchLayoutPrefs`) and in-game quick menu (`InGameQuickMenu`).
- **Authentication & Security**:
  - Email sign-in with **Supabase Auth** (registered accounts only; guest/anonymous login prohibited).
  - Encrypted token storage via `androidx.security:security-crypto` with automatic Keystore corruption recovery.
- **CI Security & Code Quality**:
  - Automated security auditing with **Gitleaks**, **cargo-audit**, **cargo-deny**, **Trivy**, **OpenSSF Scorecard**, and **CodeQL** (`.github/workflows/security.yml`).
  - Automated code quality checks with **rustfmt**, **Clippy**, **Detekt**, **ktlint**, **JetBrains Qodana**, and **SonarCloud** (`.github/workflows/quality.yml`). See [docs/CI_QUALITY_AND_SECURITY.md](docs/CI_QUALITY_AND_SECURITY.md).

## Requirements

- **Operating System**: Linux (for toolchain and native build scripts).
- **Android**:
  - `minSdk`: 26 (Android 8.0)
  - `compileSdk`: 37.2 / `targetSdk`: 36
  - Supported architecture: `arm64-v8a`
  - Android NDK `27.2.12479018`
  - JDK 17 or 21
- **Rust**: `rustup`, `cargo`, `aarch64-linux-android` target, and `cargo-ndk`.
- **Base tools**: `git`, `curl`, `unzip`, `make`.

## Initial Setup

### 1. Install the toolchain

The `scripts/setup-toolchain.sh` script checks or downloads JDK 21, Android Command Line Tools, Platform 36, Build-Tools 36, NDK `27.2.12479018`, adds the `aarch64-linux-android` Rust target, installs `cargo-ndk`, and generates `scripts/env.sh`:

```bash
./scripts/setup-toolchain.sh
source scripts/env.sh
```

### 2. Configure Supabase and signing variables

Add the required properties to `local.properties` (at the project root) or export them as environment variables:

```properties
# Path to the Android SDK (usually generated by Android Studio / Gradle)
sdk.dir=/path/to/Android/Sdk

# Supabase configuration (required for BuildConfig)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key

# Optional: Supabase administration & migrations (never bundled into the APK)
SUPABASE_PROJECT_ID=your-project-ref
SUPABASE_DB_PASSWORD=your-db-password
SUPABASE_ACCESS_TOKEN=sbp_your_personal_access_token

# Optional: signing for release builds (APK / AAB)
BALDDOG_KEYSTORE_PATH=/path/to/keystore.jks
BALDDOG_KEYSTORE_PASSWORD=your_password
BALDDOG_KEY_ALIAS=your_alias
BALDDOG_KEY_PASSWORD=your_key_password
```

### 3. Supabase database

Apply the migrations located in `supabase/migrations/` to your Supabase project:

1. `supabase/migrations/001_initial_schema.sql` — Creates the `profiles`, `game_bios`, `games`, `rooms`, and `room_messages` tables, triggers, RLS policies, and Realtime.
2. `supabase/migrations/002_seed_curated_games.sql` — Inserts the initial curated game catalog.
3. `supabase/migrations/003_private_rooms.sql` — Adds `rooms.is_private` and `idx_rooms_status_private` for private rooms.
4. `supabase/migrations/004_game_stats.sql` — Adds download/play-time counters, `user_game_stats`, and atomic RPCs (`increment_game_download`, `record_play_session`).
5. `supabase/migrations/005_leaderboards_schema.sql` — High scores table with `UNIQUE(game_id, user_id)` and strict client RLS.
6. `supabase/migrations/006_leaderboard_rpcs.sql` — Atomic RPCs (`submit_high_score`, `get_game_leaderboard`, `get_my_game_rank`).
7. `supabase/migrations/007_seed_score_configs.sql` — Initial `score_config` seed with verified `max_valid_score`.
8. `supabase/migrations/008_profile_rpcs.sql`..`014_seed_mslug3_viostorm_score_configs.sql` — Empirical RAM expressions for 22 verified games (CPS-1, CPS-2, Neo Geo, Toaplan, Konami, Irem, Data East, Technos, etc.).
9. `supabase/migrations/015_replays_storage_and_schema.sql` — `replays` Storage bucket, `high_scores.replay_path` columns, and updated leaderboard RPCs.
10. `supabase/migrations/016_match_history_and_profile_replays.sql` — Match history, session tracking, and profile replays.
11. `supabase/migrations/017_replay_verification.sql` — Headless replay verification schema and RPCs.
12. `supabase/migrations/018_fix_max_valid_score.sql` — Score validation fixes.
13. `supabase/migrations/019_public_profiles_and_social.sql` — Public profile system, social links, and registered-user constraints.
14. `supabase/migrations/020_user_follows.sql` — User follower network schema and RPCs.
15. `supabase/migrations/021_rankings_and_gamification_rpcs.sql` — Global rankings, points, and gamification RPCs.
16. `supabase/migrations/022_security_and_consistency_fixes.sql` — Consolidated RLS hardening, SECURITY DEFINER privileges, and anti-cheat fixes.
17. `supabase/migrations/023_harden_replay_sha256_and_room_messages_rls.sql` — Unique replay SHA-256 enforcement and room messages RLS hardening.
18. `supabase/migrations/024_*`..`038_harden_leaderboards_privacy_and_indexes.sql` — Score config fixes (`uccops`, `dino`, `simpsons`, `mslug3`, `snowbros`), Google OAuth & email verification, public web stats/profiles/replays RPCs, Arcade Database metadata & IPFS covers, `pg_cron` stale room cleanup, and security/privacy hardening.

## Building

### 1. Build the FinalBurn Neo core (`libfbneo_libretro.so`)

Clones FBNeo into `.cache/FBNeo` at the pinned commit and builds the deterministic core for `arm64-v8a`:

```bash
./scripts/build-fbneo-android.sh
```

### 2. Build the Rust engine and generate Kotlin bindings

For a `debug` (default) or `release` build:

```bash
./scripts/build-rust.sh debug
# or for release:
./scripts/build-rust.sh release
```

This step generates `app/src/main/jniLibs/arm64-v8a/libbalddog_android.so`, copies `libc++_shared.so`, and updates the UniFFI bindings in `app/src/main/java/uniffi/balddog_android/`.

### 3. Build the Android application

**Debug APK:**

```bash
./gradlew assembleDebug
```

> **Note:** `assembleDebug` / `installDebug` require `app/google-services.json` to include the `dog.bald.arcade.debug` client. If your `google-services.json` only registers `dog.bald.arcade`, use `./gradlew installRelease` or `./scripts/build-release.sh` (Gradle falls back to debug signing when no release keystore is configured).

**Release (APK + AAB):**

```bash
./scripts/build-release.sh
```

Generated artifacts are placed in:
- `app/build/outputs/apk/release/`
- `app/build/outputs/bundle/release/`

## Releases, Integrity & In-App Updates

Releases are automated via `.github/workflows/release.yml` on `v*.*.*` tags:
- **Integrity:** Every release publishes `app-release.apk.sha256` alongside SLSA build provenance (`actions/attest-build-provenance`) and an informative VirusTotal API v3 report link.
- **In-App Updater:** The Android app checks GitHub Releases from **Profile -> Versión y Actualizaciones**, downloads the APK with progress tracking, verifies its `SHA-256` checksum locally before installation, and launches the native Android package installer.
- **Guides:** See [docs/RELEASES_AND_UPDATES.md](docs/RELEASES_AND_UPDATES.md) and [docs/SECURITY_AND_SIGNING.md](docs/SECURITY_AND_SIGNING.md).

## Infrastructure & Maintenance

- **Automated Database Maintenance (`pg_cron`):** Supabase runs `public.cleanup_stale_rooms()` every 5 minutes via `pg_cron` (`036_enable_pg_cron_maintenance.sql`) to close orphaned netplay rooms inactive for more than 30 minutes.
- **Dual Analytics:** Android app telemetry uses Firebase Analytics (GA4) without PII ([docs/ANALYTICS.md](docs/ANALYTICS.md)), while the public web (`bald.dog`) uses cookie-free Cloudflare Web Analytics.
